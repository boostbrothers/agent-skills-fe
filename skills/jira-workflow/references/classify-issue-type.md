# 과제 유형 판별 기준

Task 디스크립션 작성 전, 상위 Initiative의 과제 유형을 판별합니다.

## 판별 기준

```
IF 상위 Initiative 티켓 유형 == "이니셔티브"
   AND Initiative 제목에 "운영과제" 포함
THEN → 운영과제

ELSE IF 상위 Initiative가 없음
   AND 상위 Epic의 프로젝트 키 == "PE"
THEN → 내부과제

ELSE → 중점과제
```

## 판별 예시

| 조건 | 유형 |
|------|------|
| Initiative 제목에 "운영과제" 포함 | 운영과제 |
| Initiative 없음 + Epic이 PE 보드 소속 | 내부과제 |
| Initiative 있음 + "운영과제" 미포함 | 중점과제 |
| Initiative 없음 + Epic이 PE 보드 아님 | 중점과제 |

| Initiative 제목 | Epic 보드 | 유형 |
|----------------|-----------|------|
| [운영과제] 예약 버그 수정 | - | 운영과제 |
| [운영과제] CS 대응 화면 개선 | - | 운영과제 |
| 없음 | PE | 내부과제 |
| [중점과제] 상담톡 채팅 기능 | - | 중점과제 |
| 홈 인텔리전스 개선 | - | 중점과제 |
| 없음 | PE 아님 | 중점과제 |

> Initiative가 없고 Epic 보드 확인이 어려운 경우 중점과제로 가정하되, 사용자에게 "중점과제로 판별했습니다. 맞나요?" 확인을 거칩니다.
