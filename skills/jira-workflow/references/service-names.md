# 서비스명 목록

`{{serviceName}}` 파라미터에 사용할 수 있는 유효한 서비스명 목록입니다.

| 번호 | 서비스명 | 설명 |
|------|----------|------|
| 1 | 똑닥앱 | 사용자 대상 모바일 앱 |
| 2 | 병원어드민 | 병원 관리자용 어드민 |
| 3 | PA | PA 서비스 |
| 4 | 직접 입력 | 위 목록에 없는 경우 사용자가 직접 입력 |

> 위 목록에 없는 서비스명은 팀 내 합의된 명칭인지 확인 후 사용합니다.

## 사용자 선택지 형식

서비스명을 자동으로 판단하기 어려운 경우 아래 형식으로 선택지를 제공합니다:

```
서비스명을 확인하지 못했습니다. 작업 대상 서비스를 선택해주세요.
1. 똑닥앱
2. 병원어드민
3. PA
4. 직접 입력
```
